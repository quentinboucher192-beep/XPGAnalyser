# =============================================================================
#  Session 11115 : LE CYCLE DE LA SIMULATION ET LA REMANENCE (lot 3).
#  Sur la copie corrigee d'Armoire_Gaz (session 11113), sans cache :
#    1. l'option Remanence cochee (la barre de l'onglet Simulation . IHM) ;
#    2. la simulation tourne : Secondes_IHM avance (le script Horloge) ;
#       Arreter : les donnees gardees (les Sorties le disent) ;
#    3. Demarrer : Secondes_IHM reprend ou il en etait ;
#    4. Redemarrer : la question ; Redemarrer : les valeurs initiales ;
#    5. Generer et redemarrer : les donnees gardees, la simulation repart avec elles ;
#    6. une ligne ajoutee au script Horloge pendant la marche : l'arret, la carte ;
#    7. Generer et redemarrer depuis la carte : seul Horloge est refait, les
#       donnees reviennent ;
#    8. l'option decochee : le demarrage repart des valeurs initiales.
# =============================================================================

attendre 2
