# =============================================================================
#  Session 75 - 1.10 : les nouveautes se voient (chantier P). Captures PNG_1050 a
#  PNG_1059, dans une COPIE de Armoire_Gaz. En mode script, rien ne s'ouvre de
#  soi-meme et les reperes sont masques : "nouveautes-relancer 1.10.0 1.8.0"
#  rejoue le premier lancement de la 1.10 pour qui vient de la 1.8 (l'etat
#  repart de zero, les reperes sont montres), "nouveautes-fenetre" ouvre la
#  fenetre comme le menu Aide > Nouveautes de cette version.
#  Les commandes : ScriptRunner.cpp, "1.10 (chantier P) : les nouveautes se voient".
#  Avant la fusion : les elements des autres chantiers (pastilles API / IHM,
#  zoom, Compiler...) n'existent pas dans cette copie - leur bulle se pose au
#  centre ; l'inspecteur, les Variables IHM, les Types IHM et l'aide existent.
# =============================================================================
attendre 3
