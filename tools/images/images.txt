#  La bibliotheque d'images de l'IHM (1.14.1, lot N6) - LA description unique.
#
#  python3 tools/images/generer_images.py --cpp src/hmi/HmiImageLibraryData.cpp
#  en tire le C++ embarque (des SVG : nets a toute taille). Chaque image est
#  DESSINEE ici, forme par forme, pour l'application : aucune image ni police
#  d'icones d'ailleurs.
#
#  Syntaxe, une ligne a la fois :
#    = Categorie                       une categorie, dans l'ordre de la bibliotheque
#    == cle | Nom | mots, cles [| LxH] une image (cle : minuscules et tirets) ; LxH :
#                                      sa grille (24x24 par defaut) ; elle se pose a
#                                      8/3 de sa grille (24 -> 64 pixels)
#    puis ses formes, une par ligne, indentees, dans la grille :
#      trait D            un chemin trace (D : la syntaxe d'un chemin SVG)
#      plein D            un chemin rempli
#      cercle cx cy r     un cercle trace          disque cx cy r     un disque
#      rect x y l h [r]   un rectangle trace       pave x y l h [r]   un rectangle plein
#      ligne x1 y1 x2 y2  un segment
#      ellipse cx cy rx ry ; ovale cx cy rx ry (rempli)
#      poly x,y ...       une ligne brisee ; contour x,y ... (fermee) ; polygone x,y ... (rempli)
#      fleche x1 y1 x2 y2 [t]           un segment et sa pointe (t : la longueur des barbes)
#      arcfleche cx cy r a0 a1 [t]      un arc (degres, 0 a droite, 90 en bas ; a1 > a0 :
#                                       sens horaire) et sa pointe en a1
#      engrenage cx cy r dents [trou]   une roue dentee ; etoile cx cy R r branches [depart] ;
#      etoile-pleine ... ; trefle cx cy r1 r2 (le trefle de la radioactivite)
#      etoiles-cercle cx cy R n r       n etoiles sur un cercle ; grille-disques x y dx dy nx ny r
#      chiffre 123 cx cy h              des chiffres dessines au trait (pastilles, compteurs)
#      image cle [x y echelle]          les formes d'une autre image, decalees, a l'echelle
#      danger cle | interdit cle | obligation cle | secours cle | incendie cle
#                                       un panneau (dans l'esprit des normes) et son pictogramme
#                                       (une autre image ; - : le panneau general)
#      brut <...>                       du SVG tel quel
#    et, apres un ; , des options : ep=1.5 (l'epaisseur ; 2 par defaut), coul=rouge (ou
#    #RRGGBB ; encre par defaut), op=0.4 (l'opacite), tirets=2,2, bout=carre,
#    regle=pairimpair (des trous), bord=coul et epb=1 (le bord d'une forme pleine),
#    tourne=a[,b...] et centre=x,y (une copie tournee par angle), fep=1.6 (l'epaisseur
#    des traits d'une image incluse, multipliee).
#
#  L'ENCRE : une image tracee seulement a l'encre est MONOCHROME, elle prend la
#  couleur choisie a l'import (la couleur du theme, ou une autre) ; une image qui a
#  ses couleurs les garde (ses traits a l'encre, s'il y en a, prennent la couleur
#  choisie). Une cle ou une categorie qui commence par _ est une aide (dessinee,
#  pas livree).
# =============================================================================
