API Studio et IHM Studio {VERSION} - Windows 10 et 11, 64 bits
==============================================================

L'analyse, l'IHM et la simulation de tes projets Control Expert (.XPG).


CE QUI EST INSTALLÉ
-------------------
Ce dossier : les applications choisies à l'installation (API-Studio.exe : le
programme de l'automate ; IHM-Studio.exe : l'IHM) et tout ce dont elles ont besoin
(SDL3.dll, le runtime Visual C++ s'il y en a un), resources\ et libs\ (les
versions livrées, qui amorcent tes données), maintenance\ (les scripts de
réparation), licences\, manifeste.json (chaque fichier, sa taille, son
SHA-256) et installation.ini (écrit par l'installateur : ne pas modifier).
Rien à ranger ici : ce dossier est remplacé à chaque mise à jour.

CE QUE TU INSTALLES, LES OPTIONS (1.14.0)
-----------------------------------------
L'installateur le demande au début : les deux applications (le choix
habituel), API Studio seul, IHM Studio seul, ou un poste d'exploitation -
IHM Studio sans l'éditeur, qui ouvre un projet (FINISH) en plein écran. Le
poste peut démarrer à l'ouverture de la session Windows et être relancé
s'il se ferme (maintenance\poste.cmd, réduit dans la barre des tâches ; trois
fermetures rapprochées l'arrêtent, Journaux\poste.log le dit). Seul ce qui
sert s'installe. Une mise à jour reprend ton choix ; pour en changer,
relance l'installateur : ce qui ne sert plus s'en va, tes données restent.
Les options : un raccourci sur le Bureau par application ; ouvrir les .xihm
et les .xapi d'un double-clic ; « Ouvrir avec API Studio » dans le clic
droit des .XPG ; une règle du pare-feu pour IHM Studio (installation pour
tous les comptes) ; la copie de secours pour Réparer (environ 130 Mo). Seules
celle de la version installée et celle de la précédente sont gardées ; sans
copie de secours, Réparer demande l'installateur.
Sans surveillance : /PROFIL=deux|api|ihm|poste, /POSTE="D:\Projets\Armoire",
/POSTEAUTO=oui|non, /POSTERELANCE=oui|non ; les cases par /MERGETASKS (par
exemple "!reserve" : sans copie de secours ; "parefeu", "bureauapi",
"bureauihm", "bureauposte", "xihm", "xapi", "xpg", "barre").

TES DONNÉES
-----------
Tes projets, ta bibliothèque (DFB, DDT, macros), ton catalogue et tes
captures sont dans ton dossier des données : Documents\XPGAnalyser par
défaut, ou celui choisi pendant l'installation. Pour les voir, les ouvrir ou
les changer : l'accueil d'API Studio ou d'IHM Studio, lien « Dossiers », ou le menu Projet
> Dossiers de l'application... Ils sont enregistrés dans
%APPDATA%\XpgAnalyzer\XPGAnalyser.ini ; tes réglages, dans
%APPDATA%\XpgAnalyzer\settings.txt (ces dossiers gardent leur nom d'origine :
tes réglages et tes données restent où ils sont).

METTRE À JOUR
-------------
Lance le nouvel installateur (API-IHM-Studio-Setup-<version>.exe). Il trouve la
version installée, la sauvegarde, ferme l'application proprement, remplace le
programme, met à jour les fichiers livrés sans écraser ceux que tu as
modifiés, puis vérifie chaque fichier.

EN CAS DE PROBLÈME (menu Démarrer > API IHM Studio > Maintenance)
-----------------------------------------------------------------
  Vérifier l'installation                rien n'est modifié
  Réparer                                diagnostic, puis réparation de ce qui est cassé
  Reprendre une installation interrompue
  Restaurer une sauvegarde               la version d'avant, tes réglages d'avant
  Réinitialiser mes réglages             mis de côté, pas effacés
  Collecter les journaux                 un zip sur le Bureau, pour le dépannage
Les journaux : %LOCALAPPDATA%\XpgAnalyzer\Journaux (installation pour toi
seul) ou %ProgramData%\XPGAnalyser\Journaux (pour tous les comptes).

DÉSINSTALLER
------------
Menu Démarrer > API IHM Studio > Désinstaller API IHM Studio (tape « désinstaller »
dans la recherche Windows), ou Paramètres > Applications > Applications
installées > API IHM Studio > Désinstaller. Tes données et tes réglages sont gardés, sauf si tu choisis de
les supprimer (ils vont alors dans la Corbeille, après la confirmation
SUPPRIMER).

L'installateur n'est pas signé : au premier lancement, Windows SmartScreen
peut afficher « Windows a protégé votre ordinateur ». Clique sur
« Informations complémentaires », puis sur « Exécuter quand même ».
