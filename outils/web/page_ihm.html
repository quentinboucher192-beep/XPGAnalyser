Cette page fait tourner l'IHM : ses vues, ses scripts, ses alarmes, la connexion et la signature. Un navigateur ne laisse pas une page joindre un appareil ni toucher au PC. Dans la page :

  • les équipements (Modbus TCP) ne sont pas reliés : leurs variables gardent leur valeur initiale ;
  • pas de ping ni de recherche d'adresses IP, pas de port série ;
  • pas de courriel ni de SMS ;
  • pas de vidéo décodée par Windows (MP4, WMV) : le Motion-JPEG (AVI) passe ;
  • pas de lecteur PDF, pas de serveur web ;
  • pas de clavier virtuel (tape au clavier du poste), pas de fenêtre Réglage PID ;
  • dans un onglet caché, le navigateur ralentit la page : garde-la affichée.

Pour tout cela : ouvre le projet dans IHM Studio, ou en poste d'exploitation (Télécharger le projet, puis Projet › Importer depuis une page web…).
