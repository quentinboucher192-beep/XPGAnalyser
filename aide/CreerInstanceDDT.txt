#! summary = Declare une variable d'un type derive, seule ou en tableau, en important le type au besoin.
#! usage = Une instance de DDT est une variable dont le type est un DDT. Le type doit donc exister AVANT. C'est pour ca que cette macro l'importe plutot que de laisser la creation echouer sur un message parlant d'un type inconnu.
#! usage = Le tableau est la forme normale ici : les blocs de la bibliotheque traitent des tableaux d'equipements, pas des variables isolees.
#! usage = Une macro se relance. C'est la regle de toutes celles-ci : relancee sur un projet ou elle a deja tourne, elle ne doit rien casser et rien dupliquer. C'est pour ca qu'elles testent avant de creer, et qu'elles disent "existe deja" au lieu de s'arreter.
#! usage = Les questions arrivent par TOURS. Ask() enregistre une question, AskNow() les pose. Une macro coupe ses tours la ou une reponse decide des questions suivantes : demander les quatre noms de section quand on vient de repondre "une seule famille" remplirait l'ecran de champs qu'on laisserait vides.
#! example = CreerInstanceDDT : type = ST_EQ_Motor, nom = Moteurs, tableau de 16
#! see = CreerInstanceDFB, EnsureLibraryItem, CreerVariable
#! param type = Le type derive : ST_IO_Ana, ST_EQ_Motor, ST_ALM_Def.
#! param type = Absent du projet, il est importe de la bibliotheque. Absent des deux, la macro s'arrete en le disant.
#! param nom = Le nom de la variable creee. Elle est toujours GLOBALE : un tableau d'equipements est lu par l'IHM et par plusieurs sections.
#! param combien = Une seule variable, ou un tableau.
#! param combien = La taille du tableau doit correspondre a celle attendue par le bloc qui le traite : DFB_EQ_MOTOR travaille sur ARRAY[0..15]. Un tableau plus petit ne se branchera pas.
#! param taille = Le nombre d'elements, quand c'est un tableau. Le tableau va de 0 a taille-1.
