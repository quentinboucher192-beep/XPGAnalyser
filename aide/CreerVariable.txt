#! summary = Cree une variable globale, ou privee a une unite de programme.
#! usage = Creer une variable qui existe deja est refuse par le projet, ce qui arreterait la macro. Celle-ci teste d'abord et se contente de le dire.
#! usage = Elle NE VERIFIE PAS que le type existe. Une variable d'un type inconnu sera creee et ne compilera pas : passez par CreerInstanceDDT pour un DDT, qui l'importe au besoin.
#! usage = Une macro se relance. C'est la regle de toutes celles-ci : relancee sur un projet ou elle a deja tourne, elle ne doit rien casser et rien dupliquer. C'est pour ca qu'elles testent avant de creer, et qu'elles disent "existe deja" au lieu de s'arreter.
#! usage = Les questions arrivent par TOURS. Ask() enregistre une question, AskNow() les pose. Une macro coupe ses tours la ou une reponse decide des questions suivantes : demander les quatre noms de section quand on vient de repondre "une seule famille" remplirait l'ecran de champs qu'on laisserait vides.
#! see = CreerInstanceDDT, CreerInstanceDFB, CreerSR
#! param nom = Le nom de la variable. Vide, la macro s'arrete plutot que de creer quelque chose sans nom.
#! param type = Un type elementaire (BOOL, INT, DINT, REAL, STRING[16]), un DDT deja present, ou un tableau : ARRAY[0..15] OF ST_IO_Ana.
#! param type = Le type n'est pas verifie ici. C'est le compilateur qui le dira.
#! param ou = Globale, ou privee a une unite de programme.
#! param ou = Une variable privee ne se voit que depuis son unite. C'est ce qu'on veut pour un compteur de travail ; ce n'est pas ce qu'on veut pour une donnee que l'IHM doit lire.
#! param unite = L'unite de programme, quand la portee est privee. La question n'est posee que dans ce cas - c'est la raison du AskNow() qui precede.
