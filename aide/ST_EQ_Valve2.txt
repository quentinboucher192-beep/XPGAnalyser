#! summary = Une vanne 2 voies : 2 commandes, 2 retours de position.
#! usage = Le contrat commun a toutes les familles d'equipement :
#! usage =   Enable a FALSE fige l'equipement - aucune sortie, aucun defaut. Un
#! usage =   equipement consigne ne doit pas remplir le journal d'alarmes pendant
#! usage =   qu'on travaille dessus.
#! usage =   ManMode fait primer les commandes Man* sur l'automatisme.
#! usage =   AckFault acquitte SUR FRONT MONTANT, et seulement si la condition a
#! usage =   disparu.
#! usage = LE DEFAUT EST MEMORISE par FaultLatch. Un thermique qui se rearme tout
#! usage = seul en refroidissant effacerait la trace de son declenchement, et
#! usage = personne ne saurait pourquoi la machine s'est arretee cette nuit-la.
#! fault 1 = Deux retours actifs a la fois. C'est PHYSIQUEMENT IMPOSSIBLE : un capteur est
#! fault 1 = casse ou mal cable. C'est le defaut que tout le monde oublie de traiter, et
#! fault 1 = celui qui fait croire a une position que la vanne n'a pas.
#! fault 2 = Aucun retour au bout de TravelMs : la vanne est bloquee, ou le capteur est
#! fault 2 = mort. Ce defaut n'existe que si HasFdc est vrai - sans retour, il n'y a rien
#! fault 2 = a attendre.
#! fault 3 = Position demandee hors de 0..Ways-1. Elle est refusee AVANT de commander quoi
#! fault 3 = que ce soit : une vanne a qui on demande la position 5 ne doit pas voir ses
#! fault 3 = sorties a zero et se croire au repos.
#! fault 4 = Le retour a disparu alors qu'aucun mouvement n'etait demande. La vanne a
#! fault 4 = bouge toute seule, ou le capteur lache.
#! param Enable = FALSE fige l'equipement : aucune sortie, aucun defaut, et les compteurs
#! param Enable = cessent d'avancer. C'est l'etat d'une machine consignee.
#! param Fault = La copie PUBLIEE de FaultLatch, posee en fin de cycle. Les sorties, elles,
#! param Fault = se coupent sur FaultLatch - c'est-a-dire dans le MEME cycle que le defaut.
#! param Fault = Les couper sur Fault laisserait l'equipement pilote un cycle de plus :
#! param Fault = vingt millisecondes pendant lesquelles on le commande alors qu'on vient de
#! param Fault = decouvrir qu'on ne sait plus ou il en est.
#! param FaultCode = Le dernier code pose, 0 quand il n'y a rien. Voir la table de cette famille,
#! param FaultCode = en tete de fichier. Il n'est efface que par AckFault.
#! param Ready = Active et sans defaut. C'est ce qu'on cable sur Available d'une rotation :
#! param Ready = un equipement en defaut est alors saute, et il reprend son rang en revenant.
#! param RunMs = Temps de fonctionnement cumule, en ms. C'est ce que DFB_SEQ_ROTATE compare
#! param RunMs = en mode 2 pour designer la moins usee ; si personne ne le relaie, ce mode se
#! param RunMs = comporte comme un ordre fixe.
#! param Starts = Nombre de demarrages depuis le dernier Reset. Un compteur qui grimpe vite
#! param Starts = est la signature d'un court-cycle - voir MinOffMs quand la famille en a un.
#! param Pos = La position atteinte, -1 tant qu'aucun retour n'est franc. -1 ne veut pas
#! param Pos = dire "au repos" : il veut dire "on ne sait pas", et c'est une difference qui
#! param Pos = compte quand on decide d'ouvrir autre chose.
#! param PosReq = La position demandee en automatique, 0..1. En ManMode c'est ManPosReq qui
#! param PosReq = est lue a la place.
#! param HasFdc = FALSE : pas de retour de position. La position est alors SUPPOSEE atteinte au
#! param HasFdc = bout de TravelMs. C'est une supposition, et elle explique pourquoi une vanne
#! param HasFdc = sans fin de course ne detecte jamais un blocage - ni le defaut 2, ni le 4.
#! param TravelMs = Temps de manoeuvre tolere avant le defaut 2. A regler au-dessus du temps reel
#! param TravelMs = mesure, marge comprise : une vanne froide met plus longtemps.
#! param Cmd = Les sorties, une par position. UN DEFAUT LES COUPE TOUTES : laisser une vanne
#! param Cmd = commandee alors qu'on ne sait pas ou elle est, c'est le contraire d'un repli
#! param Cmd = sur.
#! param Ways = Le nombre de voies, FIXE pour ce type. Il n'est pas a changer : les tableaux
#! param Ways = Cmd et Fdc sont dimensionnes en consequence.
#! see = DFB_EQ_VALVE2
#! see = DFB_ITL_MATRIX
