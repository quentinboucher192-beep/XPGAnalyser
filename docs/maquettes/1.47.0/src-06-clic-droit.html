Le clic droit : le même ordre dans toutes les listes

Sur n'importe quelle ligne, les mêmes choses à la même place. Ce qui ne s'applique pas n'y est pas ; ce qui t'est interdit y est, grisé, avec la raison.

Aller à ›
ce qui est lié : admin, licence, client, PC, commande

Filtrer sur ›
