FUNCTION Pourcent : REAL
VAR_INPUT
    Valeur : REAL;
    Max    : REAL;
END_VAR
(* la part de Max que fait Valeur, bornee de 0 a 100 *)
IF Max = 0.0 THEN
    RETURN 0.0;
END_IF
RETURN LIMIT(0.0, Valeur * 100.0 / Max, 100.0);
END_FUNCTION

Où on s'en sert

  • Dans la vue (ses objets ƒx, ses scripts, ses actions, ses alarmes) : Seuil_Haut, Pourcent(Niveau, 100.0).
  • Ailleurs (une autre vue, un script général, une alarme) : Vue_Four.Seuil_Haut, Vue_Four.Pourcent(…). Les publiques seulement ; une privée lue d'ailleurs, Générer la refuse et dit pourquoi.
  • Une popup : pareil, Pop_Reglage.Pas. Une constante calculée à l'ouverture lit les paramètres reçus : Pas := Cuve.Capacite / 20.0.

Les règles

  • Un nom pris par un objet de la vue est refusé (Vue_Four.Paliers doit rester sans ambiguïté).
  • L'aide à la saisie les propose en tête dans la vue, et après Vue_Four. ailleurs, avec leur type.
  • Les surcharges, l'import et l'export des fonctions : comme pour un symbole.
  • Dupliquer une vue duplique ses constantes et ses fonctions.

Où « Choisir une fonction… » apparaît

  • Tous les éditeurs ST : scripts généraux, de vue, de popup, de symbole ; fonctions ; opérateurs ; le code d'une constante calculée.
  • Toutes les cases à aide à la saisie : cases ƒx de l'inspecteur, actions, conditions d'alarmes, colonnes du Tableau, textes à trous.
  • Aussi au clavier : Ctrl+Maj+Espace, sans passer par la liste.

Ce que fait le sélecteur

  • Il sait le type attendu à la place du curseur (1.12.14) : « Rend un REAL » ne garde que ce qui convient ; décoche pour tout voir.
  • « Dans une expression » écarte ce qui ne s'écrit qu'en instruction (IHM_POPUP…), pour une case ƒx.
  • Insérer écrit l'appel avec ses arguments à remplir, le premier choisi ; Tab passe au suivant.
  • Les familles des fonctions du projet, de la vue, du symbole viennent en tête quand il y en a.
3 · Constantes et variables

La valeur initiale : en brut, ou en code qui rend le type

Une seule fenêtre remplace « Éléments… » et « ƒx Calcul… ». Brut : un éditeur fait pour le type (une table pour une MAP, une fiche pour une structure, une ligne par case pour un tableau…). Code : une fonction dont l'en-tête est fixe et rend exactement le type de la constante. À droite, le type expliqué. Choisis un type pour voir son éditeur.

6 · Avant de coder

À décider

Ma proposition est en vert. Réponds seulement là où tu veux autre chose.

  1. Quand se calcule une constante écrite en code ? Au démarrage, par défaut ; « à chaque ouverture » au choix, et d'office pour une popup qui lit ses paramètres.
  2. La portée par défaut d'une constante ou d'une fonction de vue ? Publique, comme les objets d'une vue (Vue.Objet.Propriété est déjà public).
  3. Le code d'une valeur initiale : RETURN, ou écrire dans le nom ? RETURN, dans une fonction à l'en-tête fixe ; écrire dans le nom de la fonction reste permis (le ST classique), et les calculs de la 1.12.7 s'ouvrent tels quels.
  4. Où mettre « Choisir une fonction… » dans la liste ? Toujours en dernier, et Ctrl+Maj+Espace pour l'ouvrir directement.
  5. Quelles std:: ajouter ? Les cases cochées de la section 4 ; « Copier ma sélection » te donne la liste à coller.
  6. L'exemple ? Un modèle de vue « Constantes et fonctions » et son exemple animé dans l'aide.
