« Choisir un type » : POINTER TO et REF_TO, choisis comme une forme

Ta demande : pourquoi dans choisir un type je n'ai aucune façon de faire 'POINTER OF', par exemple je voulais faire POINTER OF Object. Ce qui existe : le langage connaît déjà POINTER TO T (ADR(x), p^, NULL) et REF_TO T (REF(x), r^ ; REFERENCE TO s'écrit REF_TO) — le registre des types les lit quand on les tape dans la case Type. Mais le sélecteur n'offre qu'une case « REF_TO (une référence) », et rien pour POINTER TO. Proposition : une ligne Accès à trois choix, à côté de la Forme.

Les choix

1
La recherche comprend un type écrit : « pointer to obj », « ref_to t_pompe », « list of real » proposent le type entier, Entrée le prend. La case Type des grilles l'aide déjà (POINTER TO puis la liste des types).
2
Accès remplace la case REF_TO : Direct, REF_TO, POINTER TO. Les choix non permis ici sont grisés avec la raison.
3
Résultat vérifié en direct par le registre des types, comme aujourd'hui (une faute grise Choisir et dit pourquoi).
4
Le pointeur vise : seulement quand une Forme est choisie ; d'office « chaque élément » (le cas courant, celui de REF_TO aujourd'hui).
5
Les mêmes règles qu'aujourd'hui pour REF_TO, étendues à POINTER TO : dans un code (une déclaration, un retour), jamais là où il faut une place dans l'équipement.

Ce que ça écrit, et ce que le Studio vérifie

VAR
    Cible   : POINTER TO Object;           (* NULL au départ *)
    Pompe   : REF_TO T_Pompe;
    Voyants : LIST OF POINTER TO Object;
END_VAR
Cible := ADR(Pompe_1);
IF Cible <> NULL THEN Cible^.Fill := 16#2E7D32; END_IF;
✓ POINTER TO Object : permis (une locale).
⚠ Cible^.Fill sans « IF Cible <> NULL » : souligné en ambre (il peut ne rien viser).
✕ Variable IHM « Selection » : POINTER TO n'est pas permis (elle a une place dans l'équipement) — Choisir grisé.
✕ « I_Demarrable » seul : une interface s'emploie par REF_TO ou POINTER TO (déjà vérifié par Générer).

Questions pour toi

  1. Object est déjà une poignée (o := Pompe_1 ; o.Fill). Pour toi, POINTER TO Object = « un objet ou NULL » (REF_TO suffit), ou un vrai pointeur vers une variable qui tient un objet ?
  2. Permettre REF_TO / POINTER TO dans les paramètres de popup et de symbole ?
  3. Afficher « POINTER TO » même si tu as tapé « POINTER OF » (le corriger tout seul, avec un avertissement) ?
