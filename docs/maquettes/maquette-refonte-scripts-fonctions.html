Résoudre un nom

Du plus proche au plus lointain : les paramètres et locales de la fonction ; les constantes, variables, références et fonctions du script ; le propriétaire (paramètres, objets, autres scripts, fonctions de la vue ou du symbole) ; le projet (scripts généraux, fonctions, vues, symboles, énumérations, variables IHM et API) ; les bibliothèques ; le système. Chaque élément garde un identifiant stable : une référence garde aussi l'identifiant de sa cible, le renommage suit les identifiants (pas le texte). Deux candidats : une erreur qui les cite (S0402), jamais un choix silencieux. « Statique » (constantes, variables partagées : la même pour toutes les instances) ne se confond pas avec l'état d'une instance.

Le format 2 (proposition)

L'index ihm/ihm.txt garde déjà une ligne par script (script id=68 nom="Init" langage=ST evenement=Demarrage …). Il gagne une ligne par déclaration, avec son identifiant ; le fichier de code ne garde que la logique. Un projet au format 1 se lit toujours (les blocs VAR restent compris), la migration le passe au format 2 avec un rapport et une copie de l'original.



  
Excel

  

    
Copier vers Excel
Une plage de grille part en texte tabulé et en tableau HTML : les colonnes restent, les nombres sont des nombres (virgule décimale selon le poste), les noms et les types restent du texte. Ctrl+Maj+C : avec les en-têtes.

    
Coller depuis Excel
En-têtes reconnus (Nom, Type, Valeur, Visibilité, Stockage, Mode… en français ou en anglais, dans n'importe quel ordre), virgule décimale, espaces de milliers, VRAI/FAUX, pourcentages ; #N/A, #REF! refusés ; aperçu avant toute modification, une seule annulation.

    
CSV
Français (point-virgule, virgule décimale, BOM : Excel l'ouvre d'un double-clic), international, TSV ; ligne « sep= » ; protection des formules ; relecture en UTF-8, Windows-1252 (le CSV d'Excel) et UTF-16 (le « Texte Unicode »).

    
.xlsx
Un vrai classeur écrit et relu sans bibliothèque : une feuille par onglet, en-têtes figés, filtres, listes déroulantes (types du registre, visibilité, stockage, mode), feuille cachée des types. On l'édite dans Excel et on le réimporte.

    
Comme dans Excel
Sélection de plages, poignée de recopie (séries 1, 2, 3 et Seuil_1, Seuil_2), Ctrl+D, Ctrl+R, Ctrl+Espace, Maj+Espace, Ctrl+- et Ctrl+Maj+=, F2, Alt+↓, somme et moyenne de la sélection.

    
Raccourcis aussi
La table des raccourcis s'exporte et se réimporte comme les autres grilles.

  


  
Les diagnostics

  
Chacun porte un code, un niveau, un message, son script, sa fonction, sa ligne, sa colonne, sa longueur, l'identifiant de l'élément, une suggestion et, si possible, une action rapide (Ctrl+.).

  


  
Les raccourcis par défaut

  
Tous configurables (Outils › Raccourcis clavier), avec détection des conflits ; le contexte le plus précis gagne (F2 renomme dans l'éditeur, modifie une cellule dans une grille). Dans un navigateur, Ctrl+W, Ctrl+T, Ctrl+Tab et Ctrl+Maj+T sont pris par le navigateur : la maquette offre Ctrl+F4, Ctrl+, et Ctrl+F6 ; l'application, elle, les reçoit.

À trancher

  
Ctrl+L. Comme Visual Studio : couper la ligne (proposé). Ou copier la ligne. Réglable dans Outils › Raccourcis.

  
Ctrl+D dans une grille. Comme Excel : recopier vers le bas (proposé) ; dans l'éditeur, Ctrl+D duplique la ligne. Les deux contextes ne se gênent pas.

  
Le retour d'une fonction. RETURN valeur; (proposé, déjà compris par le dialecte IHM depuis la 1.10) et l'ancienne forme Nom := valeur;, gardée et comprise.

  
La récursion. Permise avec une profondeur bornée à 32 (proposé), ou interdite par défaut.

  
La visibilité des nouvelles déclarations. Public (la demande : « exposables publiquement »), avec un nom qualifié ; les locales de fonction restent locales.


  
Ce que la maquette simule

  
L'écriture des fichiers (une page web n'écrit pas sur le disque : la génération montre ce qu'elle écrirait), le format riche du presse-papiers entre deux éléments de l'explorateur (gardé dans la page ; dans l'application, un format enregistré auprès de Windows), et les raccourcis que le navigateur garde pour lui. Le reste fonctionne : l'analyse, les diagnostics, la complétion, les grilles, Excel, le renommage, la migration, l'import et l'export, Tester et Exécuter.
