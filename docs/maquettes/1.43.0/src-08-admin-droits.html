Des profils (Admin LV1, LV2…) : tu les crées, dupliques, renommes. « Tous les droits » est celui de départ.
Copier vers un admin : ses droits deviennent ceux du profil (une copie, pas un lien).

Studios et service : une licence, une offre, une révocation signée par un admin qui n'en a pas le droit est refusée partout. L'Admin : bloqué dans l'Admin.
