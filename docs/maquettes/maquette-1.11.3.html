Le carré de légende, le sélecteur de valeur, les scripts qui voyagent

À droite de chaque champ, un carré dit d’où vient la valeur. Un clic sur le carré ouvre la liste des carrés, puis le sélecteur : l’arbre de tout ce qui est disponible, filtré sur le type attendu, avec un champ résultat modifiable. Plus bas : exporter et importer les scripts d’une vue (et les opérateurs) dans un fichier .xpgst.

PropriétésActions
STEST_1 · instance du symbole STEST · Vue_Accueil
Clic sur un carré : la liste des carrés et le sélecteur. Entrée valide un champ.

À essayer

  1. Le carré rouge de Seuil : une variable mal tapée.
  2. Valider un nom qui n’existe pas : la création, avec le type et la zone (API ou IHM).
  3. Value attend un ARRAY[0..9] OF UINT : l’arbre ne montre que les tableaux de ce type.
  4. Name : Voiture sans fx est une constante, convertie en 'Voiture'.
  5. Info-bulle : ajouter un repère $…$ dans un texte.
  6. Opacité à 150 : hors des bornes, avec sa correction.
  7. Scripts (plus bas) : exporter ceux de Popup_vanne dans un .xpgst, puis importer celui de Vue_Accueil.

Les règles

  1. Sans fx, le champ est une constante, convertie dans son type. Avec fx, c’est une formule : le bouton reste allumé.
  2. Une formule qui n’est qu’une variable montre le carré de la variable (UINTS → I), pas fx.
  3. Dans le champ comme dans le sélecteur : l’aide à la saisie, les erreurs et leurs corrections, la création d’une variable inconnue.
  4. Les couleurs sont celles de l’aide à la saisie. Le carré se calcule quand la valeur change, jamais à chaque image.
