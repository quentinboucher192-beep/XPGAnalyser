Pompes : ligne 42
1
Démarrer. L'hôte clique « Démarrer une session » : il nomme la session, choisit le réseau du bureau ou aussi Internet, et reçoit un code (K7M-4QX).
2
Rejoindre. Au bureau, la session apparaît seule dans « Rejoindre » ; de loin, on tape le code. L'hôte accepte chaque entrée. Le projet arrive une fois, puis seulement les changements.
3
Voir ses équipiers. Leur pastille en haut, leur curseur sur la vue, leur nom sur la vue ou la ligne de code où ils sont. « Suivre » montre ce que voit un équipier.
4
Chacun son objet. Ce qu'un équipier modifie est réservé tant qu'il le touche (un objet, une ligne de code, une variable) : les autres le voient à sa couleur et attendent ou lui écrivent. Pas de conflit à démêler.
5
Annuler, enregistrer. Ctrl+Z annule tes gestes, pas ceux des autres. L'hôte enregistre pour tout le monde ; les versions gardent qui a fait quoi.
6
Coupures. Un équipier qui perd le réseau garde son travail et le renvoie au retour. Si l'hôte arrête, la session se ferme proprement et chacun peut garder une copie.
La licence (à décider) : démarrer une session demande « Multi-utilisateur » (ENTERPRISE, ou l'option Travail à plusieurs) ; rejoindre demande seulement sa propre licence du Studio.
La sécurité : tout est chiffré (comme le déploiement réseau d'aujourd'hui) ; le code change à chaque session ; le service ne voit que des messages chiffrés.
