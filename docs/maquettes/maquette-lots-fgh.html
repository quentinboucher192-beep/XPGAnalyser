1.12.10 · lot F

Les plages et les seuils se règlent une fois, sur la variable

Aujourd'hui, la plage 0–10 bar se retape sur la jauge, le bargraphe, la cuve et le curseur. Un seuil hors plage disparaît sans un mot, et un nom de variable tapé dans un seuil est ignoré. Avec le lot F, la variable porte sa plage et ses seuils, comme elle porte déjà son unité et son format.

Configuration › Unités et formats : six colonnes de plus

Min, Max et les quatre seuils, dans l'ordre des cuves : alarme basse, seuil bas, seuil haut, alarme haute. Une case vide n'est pas réglée. Pour une variable liée avec une mise à l'échelle, celle-ci donne la plage par défaut (en gris). Tapez une valeur, un nom de variable sans =, ou un seuil hors plage : Générer le dit tout de suite.

Les objets en héritent, sauf ce qu'on règle à la main

Choisissez un objet. La case « Format de la variable » devient « Unité, format et plage de la variable ». Une valeur héritée s'affiche en gris avec son origine. Une valeur tapée sur l'objet passe avant, et ↺ la rend à la variable. Le curseur sous le dessin simule la mesure.

1.12.11 · lot G

Une pompe, une case : la liaison Équipement et le mode État

Une pompe P1 : T_Pompe demandait trois formules sur deux objets : Valeur =P1.Marche, Défaut =P1.Defaut, et le mode sur un texte à côté. Une énumération d'état était lue « ≠ 0 = marche » : un moteur en DÉFAUT était dessiné vert et tournant.

La liaison « Équipement » : toute la structure en une case

La case Équipement prend une structure. Ses membres se lient aux rôles du symbole par leur nom : Marche, Defaut, Mode, Debit, Nom… Le tableau de correspondance se modifie, et il est mémorisé pour le type : toutes les T_Pompe se lient de la même façon. Ce qu'on règle à la main sur l'objet passe avant. Changez les membres de P1 et regardez la pompe.

L'horloge liée à une variable

Sans Valeur, l'horloge montre l'heure de l'IHM, comme avant. Avec une Valeur, elle montre une TOD, une DATE_AND_TIME, une DATE, un texte ISO 8601 ou des secondes. Elle gagne aussi un format de date, 12 h ou 24 h, et un fuseau.

Le texte défilant : les messages depuis une liste, ou les alarmes en cours

« Messages depuis » une LIST ou un ARRAY OF STRING : les messages défilent l'un après l'autre et suivent la liste en marche. « Les alarmes en cours » défile ce qui sonne, éventuellement d'un seul groupe. Sans source, rien ne change.

Le code QR jusqu'à la version 40

Le guide promettait les versions 1 à 40, mais le code s'arrêtait à la version 10 : 213 octets en M. L'encodeur va maintenant jusqu'à 40 (2 331 octets en M) et choisit le mode le plus court : numérique, alphanumérique ou octets UTF-8. L'inspecteur dit ce qui reste. Le code ci-dessous est un vrai code QR : votre téléphone le lit.

La vidéo décodée

La vidéo montrait son image d'attente et une barre qui bouclait sur la durée du fichier. Elle est maintenant décodée : Motion-JPEG en AVI sur toutes les machines, par un décodeur intégré ; MP4 (H.264), WMV et MOV sous Windows, par Media Foundation. Pour finir

Ce qui ne change pas, et comment c'est livré

Les projets existants

  • Un projet 1.12.9 s'ouvre, se génère et démarre tel quel. Les propriétés nouvelles sont absentes tant qu'elles ne servent pas.
  • Un objet garde son aspect : ses bornes écrites comptent comme réglées à la main. Un symbole sans Équipement garde ses formules. Une horloge sans Valeur montre l'heure de l'IHM.
  • Les vérifications nouvelles de Générer sont des avertissements ou des informations, jamais des erreurs bloquantes.
  • Les repères $…$ marchent dans chaque case nouvelle : $Pompe$ en Équipement, $Profil$[*].X en points, $Messages$ en messages. Dupliquer les suit.

Les versions

  • 1.12.10, lot F : plages et seuils de la variable, valeurs initiales d'un tableau de structures.
  • 1.12.11, lot G : liaison Équipement, mode État, arguments vérifiés, symboles typés.
  • 1.12.12, lot H : sommets, points depuis une source, plan à zones, référence XY, horloge, texte défilant, code QR 40, vidéo.
  • Un seul installateur, la 1.12.12, et le document de livraison avec ce qui est fait, ce qui ne l'est pas, et les essais.

Dans la maquette, ce qui est simulé : les valeurs des variables, Générer (recalculé ici en JavaScript à partir des mêmes règles), et l'image de la vidéo, dessinée au lieu d'être lue dans un fichier. Ce qui est réel : le code QR. Son encodeur suit la norme ; il a été relu par un décodeur indépendant sur les 40 versions et les 4 niveaux.
